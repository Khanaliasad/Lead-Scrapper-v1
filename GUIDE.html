Social Commerce Lead Scraper v1

The original, simplest version: find public Instagram businesses in Pakistan that show ordering signals, and check whether they have a website.

Purpose

Small Pakistani shops often sell only through Instagram DMs and WhatsApp. v1 surfaces them from public search results so you can pitch websites, ecommerce or SaaS tools. It never logs in to Instagram, bypasses bot protection or uses private APIs.

How it works

  1. Discover. For each city × category it runs 6 Brave queries, for example site:instagram.com "Karachi" "clothing" "DM to order". The other five use WhatsApp, COD, PKR, delivery and order.
  2. Filter. Keeps only Instagram profile URLs (posts, reels, stories and explore pages are dropped) and removes duplicates.
  3. Extract. Business name from the result title, a Pakistani mobile number (03xx or +92 3xx) from the snippets, and the buying signals found.
  4. Website check. Looks for external links in the snippet and searches "business name" "city" on Brave, then loads up to 8 candidate domains. A live non-social domain gives WEBSITE_FOUND; otherwise SOCIAL_ONLY_LIKELY.
  5. Score and export. Each lead gets a 0–100 score and the list is written to a CSV sorted by score.

Setup

Requires Python 3.10 or newer.

python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux / macOS
pip install -r requirements.txt

Copy .env.example to .env and set:

BRAVE_SEARCH_API_KEY=your_key_here

Never commit your .env file.

Getting a Brave API key

  1. Register at api-dashboard.search.brave.com/register.
  2. Add a credit card. It is required even for the free credits, and it becomes a live billing card once the free credit is used up.
  3. Choose the Search plan, open API Keys and generate a subscription token.
  4. Paste it into .env and set a spending cap if one is offered.

Usage

python lead_scraper.py --cities Karachi Lahore --categories clothing cosmetics --max-results 100 --output leads.csv
OptionDefaultMeaning
--citiesKarachiOne or more cities
--categoriesclothingOne or more niches
--max-results100Total leads wanted, split evenly across city × category pairs
--outputleads.csvOutput CSV
--skip-website-checkoffSkip website detection (status becomes NOT_CHECKED)

Start small, for example one city, one category and --max-results 20, to see the quality and cost first.

Output

One CSV (UTF-8 with BOM, so it opens cleanly in Excel), sorted by lead_score.

Columns: business_name, instagram_url, facebook_url, city, category, phone, whatsapp, email, website, website_status, order_signals, snippet, source_query, lead_score, confidence.

facebook_url, email and confidence exist as columns but v1 does not fill them. whatsapp simply copies phone.

Limitations

  • Instagram only, and a Brave API key is required (no free engine).
  • SOCIAL_ONLY_LIKELY is a heuristic: a new or unindexed website can be missed.
  • Only search snippets are read, so many leads have no phone number.
  • Mobile-number pattern only; landlines are missed.
  • beautifulsoup4 is installed and imported but the current code does not use it.
  • Roughly 6 Brave requests per pair plus 1 per lead for the website search.
Responsible use. Contact details are public, but using them for outreach is subject to local law, platform terms and anti-spam rules.
